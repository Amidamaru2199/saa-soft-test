# Учетные записи - Тестовое задание

Приложение для управления учетными записями, построенное на Vue.js 3 с использованием Composition API, TypeScript и Pinia.

## 🚀 Технологический стек

- **Vue.js 3** - Composition API
- **TypeScript** - Строгая типизация
- **Pinia** - Управление состоянием
- **Vite** - Инструмент сборки

## ✨ Функциональность

### Форма управления учетными записями включает:

1. **Заголовок и кнопка добавления** - Кнопка "+" для добавления новых учетных записей
2. **Подсказка** - Информация об использовании разделителя ";" для меток
3. **Список учетных записей** - Динамический список с полями

### Каждая учетная запись содержит:

- **Метка** - Необязательное поле, максимум 50 символов. Метки разделяются символом ";"
- **Тип записи** - Выпадающий список:
  - **LDAP** - Поле пароля скрывается и сохраняется как null
  - **Локальная** - Поле пароля отображается и сохраняется
- **Логин** - Обязательное поле, максимум 100 символов
- **Пароль** - Обязательное для типа "Локальная", максимум 100 символов
- **Кнопка удаления** - Удаление учетной записи

## 🎯 Логика работы

1. **Добавление** - Нажатие кнопки "+" добавляет пустую запись в конец списка
2. **Удаление** - Кнопка удаления полностью удаляет учетную запись
3. **Валидация** - Происходит при потере фокуса (текстовые поля) или изменении значения (селект)
   - Валидные поля сохраняются в store
   - Невалидные поля подсвечиваются красной обводкой
4. **Хранение меток** - Метки преобразуются в массив объектов: `[{ text: "метка1" }, { text: "метка2" }]`
5. **Персистентность** - Все записи сохраняются в localStorage и восстанавливаются при перезагрузке страницы

## 🛠 Установка и запуск

### Установка зависимостей

```sh
npm install
```

### Запуск в режиме разработки

```sh
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:5173`

### Сборка для продакшена

```sh
npm run build
```

### Предварительный просмотр продакшен сборки

```sh
npm run preview
```

## 💾 Хранение данных

Приложение использует localStorage для хранения учетных записей. Данные автоматически:
- Сохраняются при каждом изменении
- Загружаются при инициализации приложения
- Сохраняются после перезагрузки страницы
